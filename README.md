# RIDE PULSE — Uber Ride Booking & Performance Analytics

## Project Overview

RIDE PULSE is a data analytics project focused on analyzing Uber ride booking data to understand booking performance, revenue, cancellations, ride patterns, and location-based demand. The project uses Python, SQL, and Power BI to transform booking data into meaningful insights and interactive dashboards.

## Project Objectives

- Analyze total bookings and booking completion performance.
- Understand customer and driver cancellation patterns.
- Explore revenue and ride distance metrics.
- Identify high-demand pickup and drop locations.
- Analyze hourly ride demand and vehicle type demand.
- Present insights through interactive Power BI dashboards.

## Tools & Technologies

- **Python:** Data inspection, data quality analysis, data cleaning, and exploratory data analysis
- **Pandas & NumPy:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **SQL:** Data querying, filtering, aggregation, and business analysis
- **Power Query:** Data transformation and preparation
- **DAX:** Measures and KPI calculations
- **Power BI:** Interactive dashboards and visual analytics
- **Jupyter Notebook:** Python-based analysis

## Project Workflow

### 1. Data Inspection
Examined the dataset structure, column names, data types, and sample records to understand the available booking information.

### 2. Data Quality Analysis
Inspected missing values, blank fields, and potential data quality issues.

### 3. Data Cleaning
Prepared the data for analysis by addressing identified data quality issues while preserving the meaning of the original records.

### 4. Exploratory Data Analysis (EDA)
Used Python to explore booking statuses, vehicle types, booking values, ride distances, ratings, cancellations, and location-based demand.

### 5. SQL Analysis
Used SQL queries to filter, group, aggregate, and analyze ride booking data to identify useful business insights.

### 6. Power BI Dashboard Development
Used Power Query, DAX measures, KPIs, and visualizations to create an interactive dashboard with four analytical pages.

## Dashboard Pages

1. **Business Overview** — Booking performance, booking status, and demand patterns.
2. **Revenue & Ride Performance** — Revenue, booking value, ride distance, and payment analysis.
3. **Cancellations & Ride Issues** — Customer cancellations, driver cancellations, and incomplete ride analysis.
4. **Ride Demand & Location Insights** — Pickup locations, drop locations, hourly demand, and vehicle type demand.
